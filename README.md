# Weather API Service

Сервис для получения прогноза погоды с аутентификацией и возможностью сохранения избранных городов.

## 📋 Описание

RESTful API сервис, который позволяет:
- Регистрировать и аутентифицировать пользователей
- Получать прогноз погоды по названию города
- Добавлять города в избранное
- Получать прогноз для всех избранных городов

## 🚀 Технологии

- **Язык**: Go 1.25.0
- **Аутентификация**: Bearer токены (хранятся в памяти)
- **Внешний API**: OpenWeatherMap Forecast API
- **Хранение**: In-memory хранилище
- **Зависимости**: 
  - [godotenv](https://github.com/joho/godotenv) - для загрузки переменных окружения

## 🔧 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <git@github.com:axelaxd/weather.git>
cd weather
```

### 2. Настройка переменных окружения
Создайте файл .env в корне проекта:
```
API_TOKEN=your_openweathermap_api_token_here
```

Получить API токен можно на OpenWeatherMap.

### 3. Запуск приложения
go mod tidy
go run cmd/weather/main.go

## 📡 API Эндпоинты

### Публичные эндпоинты (без аутентификации)

#### Регистрация
POST /api/user/register

#### Авторизация 
POST /api/user/login

Заголовки:
```
Content-Type: application/json
```

Тело запроса:
```
{
    "login": "username",
    "password": "password123"
}
```

Успешный ответ (200 OK):
```
Authorization: <token>
```

### Защищенные эндпоинты (требуется токен)
Заголовок для всех защищенных запросов:
```
Authorization: Bearer <token>
Content-Type: application/json
```

* Получить прогноз по городу
GET /api/weather

Тело запроса:
```
{
    "name": "Moscow",
    "days": 3
}
```

* Добавить город в избранное
POST /api/favorite

Тело запроса:
```
{
    "name": "Moscow"
}
```

* Получить список избранных городов
GET /api/favorite

* Получить прогноз для избранных городов
GET /api/weather/favorite

Тело запроса:
```
{
    "days": 3
}
```

## 🚦 Сводка по ошибкам

### HTTP статусы и коды ошибок

| HTTP статус | Код ошибки | Описание | Когда возникает |
|-------------|------------|----------|-----------------|
| **400 Bad Request** | `INVALID_REQUEST` | Неверный формат запроса | Некорректный JSON в теле запроса |
| **400 Bad Request** | `BAD_DATA` | Некорректные данные | Неправильный тип данных в полях (например, строки вместо чисел) |
| **401 Unauthorized** | `NO_TOKEN` | Требуется токен авторизации | Заголовок Authorization отсутствует или пустой |
| **401 Unauthorized** | `INVALID_TOKEN` | Недействительный токен | Токен не найден в системе или истек |
| **401 Unauthorized** | `NO_USER` | Не авторизован | ID пользователя не найден в контексте |
| **409 Conflict** | `USER_EXISTS` | Пользователь уже существует | Попытка регистрации с уже занятым логином |
| **500 Internal Server Error** | `INTERNAL_ERROR` | Внутренняя ошибка сервера | Непредвиденная ошибка на сервере |

### Описание ошибок по эндпоинтам

#### Регистрация (`POST /api/user/register`)
| Ошибка | Код | Статус |
